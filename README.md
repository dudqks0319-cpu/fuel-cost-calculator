# 기름값 계산기

주행거리, 차량 연비, 리터당 기름값을 입력하면 사용한 기름량, 예상 기름값, 1km당 비용을 계산하는 모바일 우선 웹앱입니다.

## 기능

- 주행거리 `km`, 연비 `km/L`, 리터당 기름값 `원/L` 입력
- 사용 기름량, 예상 기름값, km당 비용 계산
- 빈 값, 0, 음수, 숫자가 아닌 값 검증
- 최근 연비와 기름값을 브라우저 `localStorage`에 저장
- 정적 PWA 구성: 서버, 로그인, 외부 API 없음

## 실행

```bash
npm test
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 열면 됩니다.
