기름값 계산기 지원

기름값 계산기는 주행거리, 유가, 차량 연비, 전기차 충전요금, 구매 관련 비용을 입력해 예상 유지비를 계산하는 무료 유틸리티 앱입니다.

문의하기

버그 제보, 계산값 문의, 차량 데이터 정정 요청은 GitHub Issues에 남겨 주세요.

계산값 안내

앱의 결과는 입력값과 공인/공개 차량 데이터를 바탕으로 한 예상치입니다. 실제 비용은 주행 환경, 운전 습관, 차량 상태, 유가 변동, 세금 정책 변경에 따라 달라질 수 있습니다.

개인정보

앱은 회원가입이나 서버 저장 없이 기기 내부에만 입력값을 저장합니다. 자세한 내용은 개인정보 처리방침을 확인해 주세요.
